# 毫米波信道接入协议仿真 —— 饱和吞吐量分析

## 1. 项目概述

本代码对 6 种信道接入协议在 **饱和模式**下的吞吐量性能进行仿真对比。

- **场景**：单个 AP + 40 个 STA，均匀分布在 8 个扇区内（每扇区 5 个）
- **物理层**：60 GHz 毫米波，4 阵元 ULA，MRT 波束成形，自由空间路径损耗
- **输出**：各协议在不同数据包长度（M）下的最大吞吐量、最优发送概率 q、漏检率

## 2. 文件结构

- [sim_utils.m]                      # 拓扑生成、物理层预计算、公共参数
- [run_protocol_sweeps.m]            # M 扫描主调度器
- [run_all_protocols.m]              # 一键运行全部协议
- [proto_aloha_slot.m]               # 时隙 Aloha
- [proto_aloha_conn.m]               # 连接型 Aloha
- [proto_csma_basic.m]               # CSMA/CA 基本模式（无 RTS/CTS）
- [proto_csma_rts.m]                 # CSMA/CA RTS/CTS 模式
- [proto_sub7.m]                     # Sub-7GHz 辅助接入
- [script_aloha_slot.m]              # 启动脚本：时隙 Aloha
- [script_aloha_conn.m]              # 启动脚本：连接型 Aloha
- [script_csma_basic.m]              # 启动脚本：CSMA 基本
- [script_csma_rts.m]                # 启动脚本：CSMA RTS/CTS
- [script_sub7_clean.m]              # 启动脚本：Sub-7G Clean（n_slo=0）
- [script_sub7_busy.m]               # 启动脚本：Sub-7G Busy（n_slo=10）
- [script_plot_topology_only.m]      # 绘制拓扑图
- [plot.py]                          # Python 绘图：吞吐量 vs Tp
- [results/]                         # 存储仿真结果为 .mat 文件

## 3. 五种协议说明

 **SF-CF**  ：Sensing-Free-Connection-Free：时隙 Aloha
 **SF-CB**  ：Sensing-Free-Connection-Based：连接型 Aloha
 **SB-CF**  ：Sensing-Based-Connection-Free：CSMA/CA 基本模式，仅载波侦听+退避
 **SB-CB**  ：Sensing-Based-Connection-Based：CSMA/CA + RTS/CTS
 **S7-AS ** ：Sub7GHz-Assited：Sub-7GHz 辅助

- **MLD**（MLO 节点）：在 60 GHz 毫米波信道上竞争接入
- **SLD**（SLO 节点）：仅在 Sub-7G 协议中存在，利用毫米波传输空窗期在 Sub-7GHz 信道上传输
- 除 Sub-7G 外，其他协议均为纯毫米波，所有协议只计算 MLD 吞吐量

## 4. 运行方式

### 4.1 运行单个协议

在 MATLAB 中直接调用对应脚本：
script_aloha_slot()       % 时隙 Aloha
script_csma_rts()         % CSMA RTS/CTS
script_sub7_busy()        % Sub-7G Busy
...

### 4.2 一键运行全部协议

在MATLAB中运行：run_all_protocols()
按照顺序运行SF-CF，SF-CB，SB-CF，SB-CB，S7-AS协议

## 5. 输出结果

### 5.1 .mat 文件

运行结果保存在 `results/res_M_<协议名>.mat`，包含：

| 字段 | 维度 | 说明 |
|------|------|------|
| `res_M.th` | 14×1 | 每个 M 点的最优吞吐量（归一化） |
| `res_M.best_q` | 14×1 | 每个 M 点对应的最优发送概率 |
| `res_M.miss` | 14×1 | 每个 M 点的漏检率（仅 CSMA 协议有效） |
| `M_VALUES` | 14×1 | M 扫描值列表 |

## 6. 自定义仿真

如果想修改仿真参数，编辑 `sim_utils.m` 中的 `get_common_params()`：

- **改节点数**：修改 `N_SECTORS` 和 `script_*.m` 中的 `STA_PER_SECTOR`
- **改仿真时长**：修改 `TIME_TOTAL_US`
- **改天线阵元数**：修改 `Nt`
- **改发送功率**：修改 `TX_POWER_DBM`
- **改 q 扫描范围**：修改各 `script_*.m` 中的 `Q_RANGE`
- **改 M 扫描列表**：修改 `run_protocol_sweeps.m` 中的 `M_VALUES`
